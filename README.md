# Pixel Planter

A cozy, pixel-art mini web game built with **HTML**, **CSS**, and **JavaScript** where you tend to your own virtual garden directly in your browser. Currently in active development—I'll keep adding more plants and features when I'm not busy!

## Features
* **Pot Placement:** Drag and position gardening pots anywhere in your virtual garden space.
* **Planting & Care:** Plant marigold seeds, water, and fertilize them to help them bloom.
* **Seed Harvesting:** Wait for your plants to mature and harvest new seeds.
* **Original Pixel Art:** Features hand-drawn pixel sprites (pots, seeds, and marigolds) created by me.

## Tech Stack
* **Frontend:** HTML, CSS, JavaScript
* **Art & Assets:** Hand-drawn pixel art sprites
* **Development:** Built with AI-assisted coding
* **Hosting:** GitHub Pages
